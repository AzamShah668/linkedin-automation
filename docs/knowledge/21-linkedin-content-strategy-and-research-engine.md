## Executive Summary

This document defines the **content strategy and copy rules** for the LinkedIn Post Automation Studio.
It bridges real engineering achievements with high-converting, 4-slide viral LinkedIn carousels.

---

## 🎯 Post Copy Rules (User Directives)

### MUST include:
- What was built — the engines, architecture, components, stack
- How each engine works step-by-step
- The meta-proof: "This post was generated by the system"
- A CTA question inviting comments
- Relevant hashtags

### MUST NOT include:
- Personal metrics or results (e.g., "62 jobs found", "5 applied", "0 bounces")
- Debugging war stories (e.g., "browser profile lock cost me an hour")
- Problem/solution framing (e.g., "THE PROBLEM: I was spending 3 hours...")
- Burnout or emotional narratives

**Rationale**: The post is a portfolio showcase of engineering capability, not a progress report. User directive enforced 2026-08-09.

## 🧠 The 4-Slide LinkedIn Storytelling Framework

Every carousel follows the **Master 4-Slide Visual Pack** defined in the
[`viral-architecture-visualizer`](file:///d:/linkdin%20automation/.agents/skills/viral-architecture-visualizer/SKILL.md) skill:

```text
SLIDE 1: HERO COVER (3D AI artwork + vector text overlay)
   └→ Stops the scroll. Shows the system visually.
SLIDE 2: ARCHITECTURE SPECS (HTML-rendered, Space Grotesk)
   └→ 5-layer technical deep dive with real file paths + protocol pills.
SLIDE 3: BEFORE vs AFTER (HTML + 3D avatar images)
   └→ Emotional contrast: manual grind vs full autopilot.
SLIDE 4: OPERATIONAL ROADMAP (HTML + 3D robot banner)
   └→ 5 scheduled tasks with cadences. What each does (not results).
```

## 🔬 Content Generation Workflow

When generating a new LinkedIn post:

1. **Read the skill**: `.agents/skills/viral-architecture-visualizer/SKILL.md` — every time, no exceptions.
2. **Run the generator**: `$env:PYTHONIOENCODING="utf-8"; py -3 tools/post_creator/generate_unified_post.py`
3. **Review outputs**: Verify all 4 slides in `output/posts/unified_post/` — check for gibberish text, correct content, no metrics.
4. **Dispatch**: Via Claude's `mcp-server-linkedin`, or manual upload by the user.
